# 测试范围

## 端到端原型试做

2026-10-23，个人原型在Windows及桌面PowerPoint环境中，使用使用者提供的模板试做了两篇论文：

- RPG: A Repository Planning Graph for Unified and Scalable Codebase Generation：35页，其中主讲32页、备用3页。
- Aligning Requirement for Large Language Model’s Code Generation（Specine）：33页，其中主讲31页、备用2页。

流程包括原文读取、已有译文核对或中文翻译、讲解点与逐页大纲、图表截图、PPTX制作、口语讲稿及问答、结构与字体检查，以及实际PowerPoint渲染后的视觉检查。试做中修正过代码块触及页脚、表格缺行、图轴被裁切及消融表过小的问题。

这不是独立审稿或通用质量保证。开源版保留工作流，去掉个人材料与固定机器路径，因此不能声称在任何宿主上都会复现同一版式。这些私人输出和第三方素材未纳入仓库。

## 仓库自动测试

`python -m unittest discover -s tests -v` 使用合成的最小OOXML包检查：

- 真实放映页序不同于物理文件编号时，提取顺序仍正确。
- 备注通过关系文件定位，且排除页码占位符。
- 隐藏页、显式字体与图片数可被提取。
- 引用缺项能产生提醒，但不宣称验证了文献内容。
- 自定义目录可安装技能，重复安装不会覆盖已有文件。

合成包仅用于解析测试，不是可用于正式演讲的示例PPT。CI不执行PowerPoint、不调用模型、不处理私人论文，也不证明内容正确或文本不会溢出。

## 每次真实制作仍需检查

逐项对照原文中的数值、单位、指标分母、模型配置、结论适用范围。逐页查看最新渲染，检查标题、正文、原图、备注及出处一致，检查字号与可读性。按实际讲稿和图表难度估时，真实排练优先于字数估计。

开源包的安装和解析测试覆盖Python 3.10+；当前CI计划在Linux和Windows上运行Python 3.11测试。完整幻灯片生成在其他操作系统、不同模型和其他宿主上的效果仍需使用者反馈验证。
